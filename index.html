04 - How I Work

Design Process

Four stages. Every project. The depth of each depends on the problem.

01
Discover
User research, competitive analysis, stakeholder interviews, and internal spec review before touching Figma.
02
Define
Information architecture, user flows, and wireframes. Aligning with engineering and stakeholders on scope.
03
Design
High-fidelity UI, interactive prototypes, new components added to the design system, and developer handoff.
04
Deploy
Working with engineering during implementation, reviewing production builds, iterating on real user feedback.
